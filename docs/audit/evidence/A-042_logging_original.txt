4. What changed
---------------
 - the mutex is statically initialised and never destroyed; the level and the format are atomics; the sink is
   swapped under the lock; init and shutdown may run while other threads log
 - every message is built into a local buffer, then written whole under the lock, and flushed
 - names and messages taken from a binary cannot start a second line, break the JSON or drive a terminal
   (header table); bytes that are not UTF-8 are replaced, not copied
 - UTC time stamps with milliseconds and a Z
 - an unopenable log file is reported on stderr (at WARN) instead of silently replaced by stderr
 - NULL file, function or format are tolerated; a message at level NONE (or outside the enum) is never written
 - a restart closes the previous file
